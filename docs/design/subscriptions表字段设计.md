# subscriptions 表字段设计

> 数据模型：**订阅权益登记**——一行 = 一笔上游订阅实例（覆盖期 + 额度预算 + 可选的套餐付款事实）。与 `topups`（充值入账事件）分表，对齐 NewAPI「权益 vs 入账」两分（见 `payments建模评估.md`，方案 B 已采纳）。平台只存**事实**，不做分摊计算。

---

## 1. 表定位

- **一行 = 一笔上游订阅实例**（权益），不是「一张付款单」
- 权益事实（`subscription_id` / 期间 / 总额度）抄自钱包页（`GET /api/subscription/self`）；金钱事实（付了多少、何时付）来自支付凭证，**可空**——分期、赠送、未掌握凭证时允许不填
- `subscription_id` 与日志 `other.subscription_id` **同体系直连**（事实关联，不推算）
- 数据规模：年个位数行——无需独立索引设计（`subscription_id` UNIQUE 足够）

## 2. 字段清单

| 列 | 类型 | 值来源 | 说明 |
|----|------|--------|------|
| `id` | bigserial PK | 自增 | 本地主键 |
| `subscription_id` | bigint UNIQUE | 人工录入（钱包页「订阅 #N」） | 上游订阅实例 ID；日志直连键 |
| `period_start` | timestamptz | 人工录入 | 用量覆盖期起点；左闭 |
| `period_end` | timestamptz? | 人工录入 | 期间终点；左开；未结束可空 = 进行中 |
| `quota_granted` | bigint | 人工录入（钱包页 `amount_total`） | 套餐总额度——**原始 quota 整数**（与日志 `quota` 同域；充值侧无此列，额度由 `amount × qpu` 派生） |
| `paid_amount` | numeric? | 人工录入（支付凭证） | 该套餐实付金额；币种无关纯数值；未知可空 |
| `paid_at` | timestamptz? | 人工录入（支付凭证） | **钱出手时刻**（非登记时刻）；未知可空 |
| `remark` | text | 人工填写 | 备注 |
| `created_at` | timestamptz | 系统 | **登记入库时刻**（补录审计） |

## 3. 时刻语义（三时刻钉死）

| 时刻 | 含义 | 谁写 |
|------|------|------|
| `created_at` | 作者按下「登记」 | 系统 |
| `paid_at` | 钱真实出手（凭证时间） | 人工；不知则空 |
| `period_start` / `period_end` | 用量覆盖期 | 人工（抄钱包页） |

筛选约定：**用量窗口看期间重叠**；**补录审计看 `created_at`**；**付款账看 `paid_at`（有则）**。

## 4. 决策摘要

- **不与充值同表**：时间轴不同（期间 vs 事件）；见 `payments建模评估.md` 方案 B
- **只存事实、不存比率**：`paid_amount` 与 `quota_granted` 相除得比率；不落分摊
- **额度存原始 quota**（原 payments 3.6）：与日志同域可比；美元展示现算
- **`paid_amount` / `paid_at` 可空**：社交层付款信息允许缺失；不阻塞权益登记
- **多订阅期间可重叠**（R8）：不设互斥约束

## 5. 写入与维护

| 时机 | 动作 |
|------|------|
| 人工登记 | INSERT（管理通道）；来源：钱包页 JSON 预填 + **辅助登录选用**（按 `subscription_id` 去重，已登记灰显）+ 支付凭证 |
| 编辑 / 删除 | 改错即修（人工数据） |
| 日志观测 | 仅核对提示（观测到 #N 无登记），不回填 |

## 6. 对外边界

- 参数对成员**完全公开透明**（含 `remark` / 金额）——访问主体模型裁决
- 无「应付」、无分摊字段
