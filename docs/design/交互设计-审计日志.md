## 1. 记录清单（页面主体）

时间线列表（时间倒序）：

| 列 | 内容 |
|----|------|
| 时间 | 到秒（北京时间） |
| 操作者 | `user_id` → 用户名；**系统触发的事件（如空库重建）为 NULL**，天然区分系统操作与会话操作 |
| 操作类型 | 分类标签（见 §2） |
| 内容摘要 | 关键信息（「key 小张-01 · 停用」「成员 A · 令牌重发」「支付记录 #3 · 编辑」） |

## 2. 操作类型体系（登记面的完整枚举）

| 域 | 类型 |
|----|------|
| Key | 登记 / 启用 / 停用 / 归属变更 |
| 支付记录 | 登记 / 编辑 / 删除 |
| 成员 | 开户 / 停用 / 启用 / 令牌签发 / 令牌重发 |
| 账号 | 改密 /（空库重建为系统事件，记「初始化」） |

- 每类管理面写操作一行留痕——操作者列当前恒为作者（单管理员），但**审计是不可变历史，操作者归属不能事后补写**：保留该列是前向兼容（未来若扩展多管理员 / 权限引擎，历史记录自然区分），也是审计语义的自描述原则（who did what when 的 who 是本体字段）
- 筛选：按域（Key / 支付 / 成员 / 账号）；分页（时间倒序 + 每页 50 条之类，细节随实现）

## 3. 定位边界

- 审计**只记录管理面写操作**：查询类动作（看总览、翻明细）不留痕；成员侧动作（看自己的视图）不属管理面、不在此列
- 本页无任何操作（纯只读）
